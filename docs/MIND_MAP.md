# Vendor onboarding mind map

```mermaid
mindmap
  root((Vendor application))
    Submit
      Form and documents
      JSON
      Demo samples
    Validate
      Completeness
      Country and formats
      Document signature
      Identity and name
      Registry and sanctions
      Duplicates
    Outcome
      Approved
        Already registered
      Pending
        Needs review
          Claim ownership
          Evidence comparison
          Independent bank verification
      Rejected
        Wrong or missing input
        Hard stop
        Two contradictions
        Reviewer rejection
        Apply again
          New application
          Full recheck
    Communicate
      Safe vendor wording
      One mail thread
      Delivery audit
    Protect
      Mask bank account
      Hide internal notes
      Link repeat applications
      Rate limit
```
